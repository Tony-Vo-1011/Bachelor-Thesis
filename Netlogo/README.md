# NetLogo 
This folder contains the NetLogo models and Python notebooks referenced in the thesis *Where Has All the Time Gone: The Role of Transport Connectivity and Third Places*. Only the files directly used in the thesis analysis are listed below. 
## Files Referenced in the Thesis 
### NetLogo Models 
- `personal_mobility.nlogo` Model 1 used to simulate routine movement, third-place visits, stopping behaviour, and social feedback effects. 
- `third_place_attributes.nlogo` Model 2 used to simulate third-place choice based on place attributes such as affordability, welcomingness, and safety.

### Python Experiment Notebooks
- `sweeps.ipynb` Parameter sweep notebook used to explore and select model parameter values.
- `model_1.ipynb` Runs the experiments reported for Model 1 (`personal_mobility.nlogo`).
- `model_2.ipynb` Runs the experiments reported for Model 2 (`third_place_attributes.nlogo`).

## Relation to Thesis 
These files form the simulation component of the thesis. The NetLogo models implement the behavioural mechanisms discussed in the research, while the Python notebooks are used to run experiments, collect outputs, and generate the results presented in the simulation chapters.
